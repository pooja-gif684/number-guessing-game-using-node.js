# number-guessing-game-using-node.js

A command-line number guessing game built with Node.js. The game chooses a random number from 1 to 100 and asks you to guess it. After each incorrect guess, it tells you whether your guess was too high or too low. When you guess correctly, it displays your total number of valid attempts.

## Requirements

- Node.js

## Run the game

In a terminal, navigate to the project folder and run:

```sh
node main.js
```

Enter a whole number between 1 and 100 at each prompt. Invalid entries do not count as attempts.
